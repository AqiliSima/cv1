# Sima Aqili

Krúžok: 1

Web: https://webte1.fei.stuba.sk/~xaqili/

Osobná webová vizitka vytvorená pre predmet WEBTE1.  
Web obsahuje profil, životopis, pracovné prostredie, rozvrh a interaktívnu mapu.  
Na mape je možné pridávať vlastné body a počítať vzdialenosť od FEI STU alebo môjho približného bydliska.

## Zdroje

- Moja fotografia: vlastná fotografia
- Pracovné prostredie: AI-generovaná ilustrácia vytvorená pre tento projekt
- Mapové podklady: OpenStreetMap
- Knižnica: Leaflet
- Font: Poppins, SIL Open Font License 1.1  
  https://fonts.google.com/specimen/Poppins

## AI

Použila som ChatGPT na pochopenie požiadaviek projektu a na pomoc s HTML, CSS a JavaScript kódom. AI som tiež použila na vytvorenie ilustrácie pracovného prostredia.
